# MKV Magic 0.2.3

This candidate fixes a sandbox output-access failure observed in the signed
0.2.2 app on macOS 27. Choosing a source file grants access to that file; it
does not necessarily grant permission to create another file beside it.

The app now uses the existing Save dialog when an automatic sibling output
has no directory grant. A chosen folder whose grant cannot be opened reports
the existing actionable error before processing begins. Originals, verified
commits, collision protection, and sandbox entitlements remain unchanged.

The output policy follows the relevant access checks in the existing working
branch. Its broader queue and export features are outside this release.
Regression checks cover denied directory access, Save-dialog fallback, chosen
folder failure, and collision numbering with a valid grant.

The candidate also brings in the existing read-only text presentation helper
for the media inspector. Native visual inspection found a zero-width text
area even though Accessibility exposed the parsed metadata. The text now
tracks its viewport width, with explicit readable colors and vertical sizing.
Window-layout tests and signed-app visual checks cover the correction.

This is a signed candidate. Publication still requires the downloaded-DMG
Apple Silicon, Intel, and updater acceptance records described in the release
runbook. Evidence is tracked in the
[macOS 27 audit](https://github.com/aindaco1/mkv-magic/issues/3).
