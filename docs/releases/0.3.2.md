# MKV Magic 0.3.2 beta

This maintenance release adopts Platform's shared Apple support core through the compatible desktop diagnostics API.

## Highlights

- Preserve the report preview, explicit send action, matching receipts and retry behavior.
- Include the immutable support package and license notices in corresponding source.
- Retain the exact Sparkle dependency and manual update policy.

## Encoding and compatibility

Media planning, codecs and verification rules retain their existing behavior. Compatible remux operations avoid video encoding; reviewed conversions retain the one-generation limit.

## Safety and privacy

Originals are never overwritten. Media processing runs locally. The main app remains sandboxed without network access; reviewed reports use the fixed-endpoint XPC service and updates use Sparkle's downloader.

## Current limitations

This is beta software. Image-subtitle OCR is not included. Signed artifacts, downloaded installers and physical-device acceptance are separate release gates.

## Requirements

macOS 13 or later on Apple Silicon or Intel. Existing settings, workflows and output files require no migration.

See [the migration record](../SHARED_SUPPORT_MIGRATION.md) for the independent rollback procedure.
