# MKV Magic 0.3.2

This maintenance release adopts Dust Wave Platform's shared Apple support core. Report review, explicit submission and update consent retain their existing behavior. Product media and processing behavior are unchanged.

The main application remains sandboxed without network-client access. Reviewed support reports still pass through the fixed-endpoint reporting XPC service, and update downloads remain inside Sparkle's downloader service. The release includes the immutable Platform source and license notices required to rebuild the diagnostics facade and its Foundation-only dependency. Existing workflow data, saved settings and output files need no migration.

See [the migration record](../SHARED_SUPPORT_MIGRATION.md) for dependency and rollback details.
