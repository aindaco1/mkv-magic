# MKV Magic 0.1.4 beta

MKV Magic is a local, lossless-first macOS utility for inspecting and safely
changing Matroska media. This beta improves feedback and file handling across
the app while updating the bundled Matroska tools.

## Highlights

- See an accessible progress indicator while MKV Magic discovers or inspects
  files, prepares reviews, updates or runs the queue, performs encoding tests,
  saves workflows, analyzes chapters, loads thumbnails, exports History, and
  creates and verifies outputs.
- Remove any inspected file with its row button or the Delete key. This only
  removes the item from MKV Magic; the source remains byte-for-byte unchanged.
- Save beside the original by default, with an explicit explanation in every
  output panel and the standard macOS option to choose another directory.
- Use the bundled Universal MKVToolNix 101.0 runtime, including its TrueHD
  parser fix and updated libEBML and libMatroska dependencies.
- Continue to edit metadata without encoding; clean and mux text subtitles;
  manage tracks, attachments, tags, and nested chapters; join or trim files;
  and run portable, reviewed workflows.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- MKV remains the default output, and packet copy or metadata editing is used
  whenever the reviewed change does not require transcoding.
- Software AV1 remains the preferred quality-and-size conversion when its local
  capability probe passes. HEVC VideoToolbox is the faster fallback for older
  or slower Intel hardware.
- Audio is preserved by default. Conversion is offered only after MKV Magic can
  preserve the reviewed channel-layout and sample-rate contract.

## Safety and privacy

- Originals are never overwritten. Outputs are built in private temporary
  storage, verified, committed to a new user-selected path, reopened, and
  verified again.
- Removing an item from the inspected-files list has no filesystem side effect.
  Moving an original to Trash remains a separate, explicit workflow option that
  runs only after verified success.
- MKV Magic runs locally without accounts, telemetry, media uploads,
  remote APIs, or LLMs. The only shipped network path is the explicit Check for
  Updates command through Sparkle's sandboxed helper.

## Current limitations

- Image-subtitle OCR is not included. PGS and VobSub may be preserved or
  removed, but are not converted to text.
- Progress is determinate where an executor exposes bounded stages and otherwise
  indeterminate; external media tools do not provide one reliable percentage
  contract for every operation.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims,
  background folder watching, automatic update installation, crossfades, and
  transitions are not included.

## Requirements

- macOS 13 Ventura or newer on Apple Silicon or Intel.
- Enough free disk space for a verified new output and temporary work.
- User-selected read/write access to every source and destination.

Publication remains separate from candidate creation and requires clean-account
Apple Silicon and Intel acceptance plus prior-version Sparkle replacement
against the exact candidate DMG digest.
