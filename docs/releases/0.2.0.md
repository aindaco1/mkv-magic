# MKV Magic 0.2.0 beta

MKV Magic 0.2.0 makes visible progress truthful and adds a named regression
pass across the app's common safety, editing, workflow, and queue journeys.

## Highlights

- Verified-output sheets now measure completed bounded stages instead of using
  a bouncing bar. Compatible pipelines count creation, verification, and atomic
  commit boundaries; common-format joins additionally count normalization and
  assembly boundaries.
- Batch saved-workflow queueing and standalone subtitle cleanup count completed
  items. Multi-file inspection reports the current file and total after bounded
  discovery has produced the input list.
- `mkvmerge` rendering and selected `mkvextract tracks` work now consume
  MKVToolNix 101's stable `--gui-mode` progress records. The sheet shows the
  tool-reported percentage within its current bounded stage, not as an invented
  percentage or remaining-time estimate for the whole verified workflow.
- Activity remains indeterminate when file discovery or a media tool supplies no
  honest duration, byte, frame, or item denominator. MKV Magic does not turn a
  stage count into a fabricated time estimate or media percentage.
- A new ten-flow regression suite covers intake and source preservation,
  zero-encode edits, subtitle cleanup, safe output names, compatible joins,
  one-generation planning, saved workflows and queue admission, History,
  collision-safe destinations, progress, Help, and manual-only updates.
- Verified-output History recording now has one shared execution boundary,
  reducing repeated lifecycle plumbing while retaining the existing fail-closed
  verification and commit contract.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- Bundles MKVToolNix 101.0 and FFmpeg 9.0.1.
- Metadata and track-property edits, track and tag removal, compatible subtitle
  muxing, and compatible joins remain zero-encode operations. Video or audio is
  encoded only when the reviewed operation explicitly requires conversion.
- Progress uses app-observed stage or item boundaries plus MKVToolNix's own
  percentage where `mkvmerge` or `mkvextract tracks` exposes it. A universal
  frame/time percentage for every bundled MKVToolNix and FFmpeg operation is not
  claimed in this release.

## Safety and privacy

- Originals are never overwritten. Each media-changing operation works in a
  private temporary location, verifies the result, commits to a distinct path,
  and reopens the finished output before reporting success.
- Existing destination files are never replaced; automatic destinations receive
  a collision-safe number when needed.
- MKV Magic runs locally, with no accounts, telemetry, uploads, remote media
  APIs, or LLM dependency. Update checks occur only when explicitly requested.

## Current limitations

- Image-subtitle OCR is not included.
- Discovery, encoding benchmarks, thumbnail and chapter analysis, workflow
  persistence, History export, and external-tool work without a bounded total
  still use activity spinners rather than invented percentages.
- Workflows that add an external subtitle remain single-file because each
  video/subtitle pairing requires explicit review.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims,
  background folder watching, crossfades, and transitions are not included.

## Requirements

- macOS 13 Ventura or newer on Apple Silicon or Intel.
- Enough free disk space for the verified output and temporary work.
- User-selected read/write access to every source and automatic destination.

## Candidate acceptance

This candidate remains a draft until its exact downloaded DMG passes a
clean-account Apple Silicon install and launch, a physical Intel install and
launch, the prior-version Sparkle replacement and relaunch check, the packaged
fixture with original-preservation verification on both architecture slices,
and real-file playback verification in Jellyfin/Plex.
