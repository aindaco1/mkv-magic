# MKV Magic 0.2.2 beta

MKV Magic 0.2.2 updates the native window layout and build verification for
macOS 27 and Xcode 27 / Swift 6.4.

## Highlights

- Fit the initial app window within the current display's usable area while
  retaining the shared content-size policy. Compact displays no longer start
  with part of the native window outside the visible frame.
- Keep unchanged-byte fixture checks compiling under Swift 6.4 without changing
  the original-preservation contract.
- Stage hosted sandbox checks in an accessible location and build Sparkle's
  update acceptance driver with a deployment target supported by Xcode 27.
- Stage local package and updater checks in the repository's generated build
  directory too, avoiding private temporary-directory sandbox denials.
- Preserve the Universal media runtime, local-only app sandbox, explicit update
  checks and verified-output safeguards from 0.2.1.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- Bundles MKVToolNix 101.0 and FFmpeg 9.0.1. Both processor slices expose the
  same reviewed tool versions, codecs, filters, local-only protocol policy, and
  minimum macOS version.
- Metadata and track-property edits, track and tag removal, compatible subtitle
  muxing, and compatible joins remain zero-encode operations. Video or audio is
  encoded only when the reviewed operation explicitly requires conversion.

## Safety and privacy

- Originals are never overwritten. Each media-changing operation works in a
  private temporary location, verifies the result, commits to a distinct path,
  and reopens the finished output before reporting success.
- Existing destination files are never replaced; automatic destinations receive
  a collision-safe number when needed.
- MKV Magic runs locally, with no accounts, telemetry, uploads, remote media
  APIs, or LLM dependency. Update checks occur only when explicitly requested.

## Current limitations

- Image-subtitle OCR is not included.
- Activity remains indeterminate when no trustworthy duration, byte, frame,
  stage, or item denominator exists.
- Workflows that add an external subtitle remain single-file because each
  video/subtitle pairing requires explicit review.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims,
  background folder watching, crossfades, and transitions are not included.

## Requirements

- macOS 13 Ventura or newer on Apple Silicon or Intel.
- Enough free disk space for the verified output and temporary work.
- User-selected read/write access to every source and automatic destination.

## Candidate acceptance

This candidate remains a draft until its exact downloaded DMG passes a
clean-account Apple Silicon install and launch without the Intel-component
warning, a physical Intel install and launch, the prior-version Sparkle
replacement and relaunch check, the packaged fixture with original-preservation
verification on both architecture slices, and real-file playback verification
in Jellyfin/Plex.
