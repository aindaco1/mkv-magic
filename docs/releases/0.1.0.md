# MKV Magic 0.1.0 beta

MKV Magic is a local, lossless-first macOS utility for inspecting and safely
changing Matroska media. This first public-beta candidate focuses on common
Jellyfin and Plex library work while preserving source files until a new output
has been reopened and verified.

## Highlights

- Inspect video, audio, subtitle, chapter, tag, and attachment facts with the
  bundled Universal FFmpeg and MKVToolNix runtime.
- Edit segment titles and track names, languages, playback flags, and roles
  without encoding; remove tracks with a zero-encode remux.
- Add external SRT, ASS, or SSA subtitles and clean external or embedded text
  subtitles with deterministic advertisement, whitespace, and English OCR
  rules. Every proposed spelling change remains individually reviewable.
- Extract one selected embedded Matroska SRT, ASS, or SSA track to an exact,
  separately verified sidecar without changing the MKV; multiple eligible
  tracks receive an explicit chooser.
- Extract one selected non-empty Matroska attachment up to 512 MiB into an
  exact, separately verified file without changing the MKV; multiple eligible
  attachments receive a filename, type, and size chooser.
- Remove one or more explicitly selected Matroska attachments in a zero-encode
  verified MKV copy while preserving all retained attachments, media tracks,
  tags, metadata, and nested chapters; the original stays unchanged.
- Convert one selected MP4/M4V/MOV TX3G text track to a separate verified UTF-8
  ASS sidecar without changing the video; multiple timed-text tracks receive an
  explicit chooser.
- Create and edit nested Matroska chapters, generate interval chapters, review
  local scene/black/silence suggestions, preview nearby frames, and explicitly
  flatten chapters for Jellyfin compatibility.
- Join compatible MKVs without encoding, or review a common-format join that
  packet-copies compatible lanes and encodes each affected video lane no more
  than once.
- Fast-trim MKVs at disclosed keyframes without encoding, or use exact numeric
  in/out points with one reviewed AV1, HEVC, H.264, or ProRes generation when
  the encoder is verified on the current Mac.
- Convert an eligible complete MKV, MP4, M4V, MOV, or chapter-free WebM through
  one reviewed AV1, HEVC, H.264, or ProRes generation while packet-copying
  compatible audio by default. MKV chapters remain exact; inspected MP4/MOV
  chapters become one default nested Matroska edition.
- Remux compatible MP4, M4V, MOV, or chapter-free WebM media to MKV with zero
  encodes, exact copied-packet verification, preserved reviewed track metadata,
  and MP4/MOV chapters translated into Matroska chapters.
- Build portable plain-language workflows, including a lossless-first condition
  that leaves existing AV1/HEVC video untouched, one locally verified video
  conversion, and an optional fused AAC, Opus, AC-3, E-AC-3, or FLAC audio
  policy; review their exact impact, run them immediately, or add eligible work
  to a durable resource-aware queue. A conversion recipe also accepts bounded
  MP4, M4V, MOV, and chapter-free WebM input when it performs one video
  conversion; its reviewed output is always MKV.
- Review privacy-safe History, retry or recover queue work, and optionally move
  a source to Trash only after verified success.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- MKV is the default output. Current editing, subtitle, chapter, join, and trim
  execution is intentionally Matroska-focused.
- Packet copy is preferred. Software AV1 is the preferred quality/size choice
  when its local capability probe passes; HEVC VideoToolbox is the faster
  fallback for older or slower Intel hardware.
- Static HDR10 can be preserved for supported AV1/HEVC exact trims and
  uniform-HDR joins. Mixed validated HDR10 and BT.709 SDR joins can be reviewed
  as tone-mapped SDR.
- Audio is preserved by default. Explicit AAC, Opus, AC-3, E-AC-3, or FLAC
  conversion is offered only when the bundled runtime can preserve the reviewed
  layout and sample-rate contract.

## Safety and privacy

- Originals are never overwritten. Every media result is created in private
  temporary storage, semantically audited, committed to a new path, reopened,
  and audited again.
- MKV Magic runs locally without accounts, telemetry, media uploads, remote
  APIs, LLMs, or an ambient Homebrew dependency. The only shipped network path
  is the explicit Check for Updates command through Sparkle's sandboxed helper.
- Saved workflows contain portable intent rather than media paths, track IDs,
  subtitle text, or per-file review choices.
- Support exports are opt-in, local, size-bounded, and exclude filenames,
  personal paths, titles, subtitle text, raw tool output, and exact timestamps.

## Current limitations

- Image-subtitle OCR is not included. PGS and VobSub may be preserved or removed
  as tracks, but MKV Magic does not extract them as sidecar artifacts or convert
  them to text.
- Direct attachment extraction creates one regular file at a time. Attachment
  add, replace, remove, batch, saved-workflow, and queue actions are not yet
  included.
- Standalone conversion creates MKV from an eligible inspected MKV, MP4, M4V,
  MOV, or chapter-free WebM. MKV input may retain audio, subtitles, attachments,
  and exact nested chapters under its existing preservation contract. Common
  input requires one video, no subtitles or attachments, unambiguous chapter
  and data facts, known container metadata, and complete supported color facts.
  Compatible audio is packet-copied and fingerprinted; otherwise the user must
  choose a verified layout-preserving audio conversion. Chaptered WebM, inline
  TX3G conversion,
  arbitrary data, unknown codecs, multiple video tracks, incomplete facts, and
  non-MKV output are refused rather than guessed. **Remux to MKV…** remains the
  zero-encode option for compatible common input. The separate TX3G-to-ASS
  action does not yet remux its result into the video. MP4/MOV and WebM output
  are not implemented.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims, and
  ambiguous or incomplete color facts fail closed rather than guessing.
- Background folder watching, automatic update checks, automatic installation,
  crossfades, and timeline transitions are intentionally absent.
- Some operations refuse source tags, unsupported subtitle/data layouts, or
  multiple-video-track inputs until their preservation contract is implemented.
- Saved-workflow audio conversion applies one target policy to every retained
  audio track. It may run alone for eligible MKV input or fuse into one video
  conversion process; per-track workflow conversion is not included yet.

## Requirements

- macOS 13 Ventura or newer.
- Enough free disk space for a verified new output and temporary work.
- User-selected read/write access to every source and destination.
