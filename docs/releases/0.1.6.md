# MKV Magic 0.1.6 beta

MKV Magic is a local, lossless-first macOS utility for inspecting and safely
changing Matroska and related media. This beta adds reviewed batch operations,
polishes spacing across the native interface, and makes failed verification
easier to diagnose without weakening privacy or output checks.

## Highlights

- Command-click or Shift-click inspected files to work with a batch. Delete
  removes all selected rows from MKV Magic while leaving every source file
  untouched.
- Select multiple standalone SRT, ASS, or SSA files and choose **Clean
  Subtitle…**. MKV Magic previews each file, shows ready, no-change, and blocked
  results, then creates one independently verified output per ready subtitle.
- Select multiple media files before opening Workflows to compile a portable
  recipe separately for every source. Applicable jobs enter the Queue
  independently; already-satisfied or unsupported items are explained first.
- Batch outputs stay beside each source by default, or one alternate folder can
  be chosen for all ready files. Existing destinations are skipped rather than
  overwritten. Trash-after-verified-success remains explicit and off by
  default.
- Progress, History, Inspector actions, Queue, workflows, join, trim, chapters,
  attachments, tags, encoding, and Help now share consistent native spacing and
  minimum-size behavior. History details remain readable in Dark Mode.
- Failed jobs export a fixed privacy-safe category. Chaptered MP4 remuxes accept
  only bounded container time-base rounding for chapter starts while retaining
  strict track, metadata, packet-copy, title, attachment, and identity checks.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- Batch subtitle cleanup does not encode media. Saved workflows retain their
  existing lossless-first planning: metadata uses property editing, compatible
  tracks use packet copy, and selected encoding operations are fused where the
  reviewed plan permits it.
- MKV remains the default output. Software AV1 remains the preferred explicit
  full-transcode choice when its bundled capability check passes; HEVC
  VideoToolbox remains the faster fallback for older or slower Intel hardware.
- Audio and video are preserved by default. Each selected workflow must contain
  an explicit conversion card before either stream type is encoded.

## Safety and privacy

- Originals are never overwritten. Each output is created in private temporary
  storage, verified, committed to a new path, reopened, and verified again.
- One failed or blocked batch item does not delete another item's successful
  output. Existing output paths are skipped, cancellation removes temporary
  work, and source files remain unchanged unless Trash after verified success
  was explicitly selected for the reviewed workflow batch.
- The privacy-safe support report includes coarse media facts, lifecycle stages,
  and a fixed failure category. It excludes filenames, paths, titles, subtitle
  text, custom workflow names, raw tool output, and exact timestamps.
- MKV Magic runs locally without accounts, telemetry, media uploads, remote
  APIs, or LLMs. The only shipped network path is the explicit Check for Updates
  command through Sparkle's sandboxed helper.

## Current limitations

- Image-subtitle OCR is not included. PGS and VobSub may be preserved or
  removed, but are not converted to text.
- Batch subtitle cleanup applies the default deterministic suggestions. Open a
  subtitle individually when you need to restore a specific proposed cue or
  event change.
- Workflows that add an external subtitle remain single-file because each video
  and subtitle pairing requires explicit review.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims,
  background folder watching, crossfades, and transitions are not included.

## Requirements

- macOS 13 Ventura or newer on Apple Silicon or Intel.
- Enough free disk space for every verified new output and its temporary work.
- User-selected read/write access to every source and destination.

Publication remains separate from candidate creation and requires clean-account
Apple Silicon and Intel acceptance plus prior-version Sparkle replacement
against the exact candidate DMG digest.
