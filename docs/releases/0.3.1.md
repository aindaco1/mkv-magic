# MKV Magic 0.3.1 beta

This maintenance release shares update and reviewed-report infrastructure with
other Dust Wave apps through an exact Platform revision.

## Highlights

- Use the shared Sparkle controller with the existing manual update behavior.
- Use shared bounded transport inside the isolated reporting XPC service.
- Preserve the report preview, explicit send action and existing issue grouping.

## Encoding and compatibility

Media planning, supported codecs and verification rules retain their existing
behavior. Compatible remux and metadata operations avoid video encoding; reviewed
conversion plans retain the one-generation limit.

## Safety and privacy

Originals are never overwritten. Media processing runs locally. The main app
has no network access; only the reviewed report helper and Sparkle downloader
have their existing limited network roles. Reports require explicit review.

## Current limitations

This is beta software. Image-subtitle OCR is not included. Clean-account physical
hardware and prior-version updater acceptance must identify the exact installer;
source tests alone do not establish those results.

## Requirements

macOS 13 or later on Apple Silicon or Intel. Actual encoding support depends on
the Mac and the installed macOS version.
