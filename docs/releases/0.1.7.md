# MKV Magic 0.1.7 beta

MKV Magic 0.1.7 fixes a three-file lossless-join failure and removes repeated
save-location prompts while preserving its strict verified-output contract.

## Highlights

- Lossless joining can continue when MKVToolNix completes with a warning. A
  warning is never treated as proof of success: MKV Magic still verifies the
  exact reviewed tracks, packets, metadata, nested chapters, unchanged sources,
  and final reopened output before saving it.
- Media outputs now save beside their source automatically by default. Open
  **MKV Magic → Settings…** to remember one default folder or switch to **Ask
  where to save every time**.
- Automatic saves never overwrite an existing file. MKV Magic adds a number to
  the proposed output name when necessary.
- Delete and Forward Delete remove every selected row from the inspected-media
  list together. They do not delete or modify the source files.
- Batch subtitle cleanup and batch saved workflows inherit the remembered
  default folder while keeping their existing per-file review.
- Future privacy-safe reports distinguish lossless-join tool, source, chapter,
  and final-audit failures without exporting raw tool text or private paths.

## Encoding and compatibility

- Requires macOS 13 Ventura or newer and ships as one Universal app for Apple
  Silicon and Intel Macs.
- Bundles MKVToolNix 101.0 and FFmpeg 9.0.1. A real three-file
  H.264/AAC/SubRip join passes with both bundled architecture paths.
- Metadata and compatible joins remain zero-encode operations. Video and audio
  conversion still occurs only when the reviewed operation requires it.

## Safety and privacy

- Originals are never overwritten. Outputs are produced in temporary storage,
  verified, committed to a new path, reopened, and verified again.
- MKV Magic runs locally, with no accounts, telemetry, uploads, remote
  APIs, or LLM dependency. Update checks occur only when explicitly requested.

## Current limitations

- Image-subtitle OCR is not included.
- Workflows that add an external subtitle remain single-file because each
  video/subtitle pairing requires explicit review.
- HDR10+, HLG, Dolby Vision, SDR-to-HDR conversion, ordered-edition trims,
  background folder watching, crossfades, and transitions are not included.

## Requirements

- macOS 13 Ventura or newer on Apple Silicon or Intel.
- Enough free disk space for the verified output and temporary work.
- User-selected read/write access to every source and automatic destination.

## Candidate acceptance

This candidate remains a draft until its exact DMG passes clean-account Apple
Silicon and physical Intel installation checks, the prior-version Sparkle
replacement check, and real-file playback verification in Jellyfin/Plex.
